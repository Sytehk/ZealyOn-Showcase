# ZealyOn

**Fintech and trading technology**

ZealyOn is a strategy-focused product for insights, alerts, account balances, and checkout. It brings together mobile and web experiences for people who want a clearer view of their strategy activity.

## Project scope

- Cross-platform mobile and web product work
- Strategy and market-data services
- API, account, and data integrations
- Ongoing feature development and maintenance

**Technology:** Flutter and Dart, Rust services, Supabase and PostgreSQL, API integrations.

This repository contains a public project summary only. Product source, credentials, customer data, and private operational details are not included.
